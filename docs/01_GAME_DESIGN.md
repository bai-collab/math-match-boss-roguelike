# 01｜完整遊戲循環與操作

## 1. 主循環

`首頁／角色選擇 → 局外商店／練功房 → 開始新局(seed) → 第 0～9 層地圖 → 選擇節點 → 戰鬥／商店／營火／事件／試煉 → 獎勵 → 下一層 → Boss → 結算（勝／敗）→ 局外資源 → 再來一局`

每局開始，將局外升級等級**快照**到 `RunState`；冒險中局外商店的變更只作用於下一局。

## 2. 戰鬥畫面布局

- **上區**：雙方 HP、護盾、怪物名稱、弱點數字 `W`、弱點特殊條件（例：至少四顆）、怪物下回合意圖；Boss 另顯示階段與破防指示。
- **中區**：玩家像素角色、怪物 Sprite、命中／護盾／治療特效，所有戰鬥效果與文字數字一致。
- **下區**：6×6 三色數字盤，清晰顯示每顆 1～9；指標拖曳或手指滑動，繪出連線路徑。
- **路徑預覽**：隨選取即顯示珠子數 `n`、目前總和 `S`、與弱點差距、將使用的顏色技能；只有放開且符合規則才結算。
- **操作列**：回合剩餘行動、結束回合、提示（可選）、聲音設定、遊戲規則。錯誤操作可取消，不扣回合。

## 3. 珠子與連線

- **顏色**：`red` 攻擊、`blue` 產生護盾、`green` 治療生命。每色同時附圖案（劍／盾／愛心）以避免只靠顏色辨識。
- **數字**：初始為 1～9 的整數；後續道具可修改數字，但不能出現非法值。
- **連線**：上下左右（曼哈頓距離 = 1）；相同顏色；3～6 顆；不可重複座標；不接受斜向與穿越。長度上限是可調預設。
- **提交**：拖曳時先呈現預覽；放開且合法才消除並結算；無效路徑保留盤面且不扣行動。手機需要可取消方式，避免手指遮擋讀數。
- **掉落**：由上方填補空位，再生成新珠；補充的隨機序列由遊戲 RNG 決定，保存 RNG 狀態。
- **連鎖**：初版不做自動連鎖攻擊，也不讓非玩家選擇的掉落觸發弱點倍率；未來可提供特效但不得誤記成學生的作答。

## 4. 行動與戰鬥回合（初版提案）

- 玩家回合可成功消除 **2 條路徑**；每次有效路徑用掉 1 次行動；可提前結束。
- 玩家行動完成後，怪物依事先公開的意圖執行動作，護盾先吸收傷害，再扣生命。
- 一條連線只產生一種效果（取珠子顏色），弱點共鳴使**本次該色效果**增加，不同色不相互強制合併。
- 若怪物 HP 降至 0（普通怪），進入勝利；Boss 需符合階段破防條件（見 `05_COMBAT_BOSSES.md`）。
- 綠色治療不超過 `maxHp`；藍色護盾有上限，初版可設 `maxShield = maxHp`，戰鬥開始新敵人護盾歸零。

## 5. 遊戲節奏

- 戰鬥短：普通怪具有可辨識的弱點與 1 項意圖；菁英通常增加條件而非只加血。
- 角色強：讓「計算正確」比「一直堆傷害」有價值；弱點倍率與破防明顯可見。
- 回饋可解釋：出現 `3+5+9=17 ✓，弱點命中 ×3`，而不是只飄出莫名其妙的傷害數字。
- 玩家有選擇：即使沒有紅色精確解，可改走藍色防禦／綠色治療；若確實缺少任何可行解，系統提供可預期的救援。

## 6. 操作／資訊可用性

- 電腦：滑鼠拖曳；鍵盤／方向鍵逐格選擇作為可及性替代。
- 手機：拖曳連線、按鈕至少約 44 CSS px、盤面數字清楚，不允許 viewport 縮放導致誤觸。
- 色盲／單色顯示：每顆珠有圖案／外框樣式＋數字，不以純紅藍綠區辨。
- 顯示「弱點條件」及即將發動的敵人攻擊；避免未告知就懲罰失誤。
- 自動儲存於切換節點、完成一次回合或關卡後，避免刷新造成進度遺失。

## 7. 初始畫面清單（可驗收）

1. MainMenu：新局／繼續／局外成長／練功房／說明／聲音。
2. CharacterSelect：選角色、能力、解鎖條件。
3. TowerMap：節點路線、已走／可走／未走狀態。
4. Battle：怪物弱點、盤面、行動、預覽與結果。
5. Reward：遺物或局內資源三選一（初版可先選一）。
6. Camp：回血或調整局內能力。
7. Shop：局內商店，用本局貨幣購買。
8. MetaShop：局外永久強化，使用跨局貨幣。
9. RunResult：勝敗原因、數學紀錄摘要、取得貨幣。
10. Settings：音樂、音效、減少動態、輸入提示與資料管理。

## 8. 不要誤讀先前「合十十倍」

這是最初想法，後來使用者提出怪物數字弱點，已成為更優先的核心。可把「合計 10」設為遊戲內特定敵人／特殊遺物／每日挑戰，但不能把所有怪物都固定成 10，亦不應無條件讓所有顏色技能 ×10。
