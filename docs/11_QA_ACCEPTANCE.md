# 11｜驗收計畫與測試矩陣

> **狀態：規格已寫，測試尚未執行。** 下列「預期」不是「實際通過」。開發者必須補上 command、date、result、seed、環境與 commit SHA。

## A. 數學規則（P0 必過）

| Test ID | 輸入／情境 | 預期 |
|---|---|---|
| M01 | 同色連續三珠 [3,5,9]，W=17，紅色 | `sum=17, exact=true, damage=18`（初始 base=2） |
| M02 | [2,3,5,7]，W=17，四珠 | `sum=17, exact=true, damage=30` |
| M03 | [4,6,8]，W=17，藍色 | `sum=18, near=true, shield=7` |
| M04 | [1,1,1]，W=17，綠色 | `sum=3, normal, heal=6`（再套 HP cap） |
| M05 | 兩珠路徑 | 無效，不扣行動或改盤面 |
| M06 | 七珠（預設 max=6） | 無效，不扣行動或改盤面 |
| M07 | 斜向相鄰 | 無效 |
| M08 | 重複使用同一座標 | 無效 |
| M09 | 其中一珠顏色不同 | 無效 |
| M10 | 盤外或 null tile | 無效 |
| M11 | `S=W±1` | 倍率 1.25，而非精確 3 |
| M12 | `S≠W` 且非差 1 | 倍率 1 |
| M13 | 青少年或成人使用不同顯示語言 | 數學核心輸出一致，與 UI 文案無關 |

## B. 盤面與可解性（P0/P1 必過）

| Test ID | 測試 | 預期 |
|---|---|---|
| B01 | 1,000 seed × weakness=8,12,17,22,25 | 對每種條件產生至少一條合法紅珠精確路徑 |
| B02 | `minChain=4`, `target=18` | solver 找到的路徑至少四珠且和為 18 |
| B03 | 同 seed/config 兩次生成 | 結果 byte-for-byte 一致（序列化時欄位順序固定） |
| B04 | 消除後盤面無解 | 自動重整且重整後有解，不扣玩家行動 |
| B05 | 非法 target（超出可表示範圍） | 配置驗證失敗、不能進戰鬥 |
| B06 | 任意合法路徑 | `validatePath(findWeaknessPaths(...))` 通過 |
| B07 | 路徑超過盤面／0／負數／NaN | 不可提交，不得破壞 state |
| B08 | 同一 actionId 重複提交 | 只結算一次、只消除一次、只扣一次行動 |
| B09 | 同一 seed 在不同裝置 | 在相同版本與邏輯條件下獲得相同的可重播 domain 結果 |

## C. Boss 與戰鬥（P2 必過）

- **C01** 第 1 階 `W=12 n≥3`，紅色精確命中可破封印。
- **C02** 第 2 階 `W=18 n≥4`；三珠即使合成 18 也**不能破封印**，四珠可以。
- **C03** 第 3 階 `W=25`，前階段未完成時不得跳階。
- **C04** Boss 在封印未破時，普通傷害最多使目前階段 HP 降到 1。
- **C05** 藍／綠精確命中有護盾／恢復共鳴，但預設不破 Boss 封印。
- **C06** HP 不超過 maxHp、shield 不超過 cap、敵人扣盾再扣 HP。
- **C07** 兩次玩家有效行動後進入敵人回合；無效拖曳不耗行動。
- **C08** 完成最後階封印且 HP 歸零後才進勝利結算；不得重複領獎。
- **C09** 關閉音效／減少動畫不改變結果與 RNG。
- **C10** HUD 顯示的數字與 `reduceBattle()` 實際結算一致。

## D. Roguelike 與局外（P3 必過）

- **R01** 地圖正好 10 層，第 9 層只有 1 個 Boss。
- **R02** 每個有效節點 id 唯一、連線只前往下一層相鄰六角格。
- **R03** 第 0 層入口 2～4 格，每個一般樓層 2～5 格。
- **R04** 同 seed 地圖結構和節點類型一致；不同 seed 有可量化多樣性。
- **R05** 地圖全局在 2～4 有營火、3～5 有商店、4～6 有菁英。
- **R06** 不可跳過可走集合、不能回頭重複領取同一節點獎勵。
- **R07** 擁有有效初始入口到 Boss 的路徑；每個可選節點可抵達 Boss。
- **R08** 局外永久升級在新局快照，中途變動不改變現行局的效果。
- **R09** 試玩與自動示範不更動永久貨幣／解鎖／成就。
- **R10** 失敗、勝利、放棄時只結算一次局外貨幣。

## E. 存檔、音效與可及性（P3/P4）

- **S01** 進行中戰鬥刷新後，怪物階段、盤面、HP、RNG、行動、遺物一致。
- **S02** 壞檔或未知版本不能靜默覆寫，介面有顯示提示。
- **S03** 沒有 AudioContext 或被瀏覽器阻止音效時，遊戲仍可操作。
- **S04** 手機直式寬 390px 高 700px、桌機 1366×768，HUD 盤面不重疊或切字。
- **S05** 鍵盤替代操作可用；顏色以外有符號；提示不靠閃爍。
- **S06** 音量可分別調整，切到背景可暫停音樂；沒有音樂 API 金鑰。
- **S07** 減少動態開啟時動畫停用但結算一致。
- **S08** 學習事件預設僅本機，能關閉與清除，不記可識別學生個資。
- **S09** 靜態打包可部署，核心玩法離線可啟動（依部署方式需要對應本地資產）。

## F. 建議自動化測試命令（待建立 package.json）

```bash

npm run typecheck
npm run test
npm run build
```
