# 10｜P0–P4 實作路線圖（AI 任務拆解）

> 這是**建議工作順序與交付契約**，不是承諾日期。每一階都先完成可執行測試再合併；不得因為將來有功能就聲稱目前已實作。

## P0：可靠的純邏輯核心（最優先）

**工作**

- 建立 TypeScript / Vite / Phaser / Vitest 專案骨架（載入空白場景即可）。
- 新增 config 統一存數學公式與弱點預設。
- 實作 `validatePath()`、`sumPath()`、`evaluatePath()`、`calculateEffect()`；以純函式測試。
- 實作 seeded RNG、`findWeaknessPaths()`、`generateSolvableBoard()`；測試「必有紅珠弱點解」。
- 定義 `GameEvent`、`BattleState`、`MapNode`、`MetaState` 型別及 JSON 資料驗證草案。

**驗收**：TypeScript strict 無錯；至少 1,000 seed 的盤面可解與 determinism 測試實際成功；數學公式範例結果一致；`npm run dev` 能開啟頁面；附測試輸出與摘要。

## P1：數字珠可玩原型

**工作**

- 6×6 盤面，三色＋圖案、1～9 數字；鼠標拖曳／手機觸控連線。
- 預覽 `n,S,W,差值,倍率`，不符合法連線不可提交。
- 消除、落珠、填補、重整、弱點解保證。
- 每次消除產生同一筆事件，畫面、數學紀錄與玩法一致。

**驗收**：可反覆合法消除；無效操作不改盤面／RNG／行動；手機連線可用；顏色以外仍可識別。

## P2：第一個完整 Boss 戰（最快取得遊玩回饋）

**工作**

- HP、護盾、治療、怪物攻擊預告、兩次玩家行動、結束回合。
- 數字魔龍三階段 12→18（至少四消）→25，完成破封印才能換階。
- 戰勝／戰敗／重新開始，先用方塊占位動畫。
- 加入戰鬥事件 log、簡單測試頁與基準平衡參數調整介面。

**驗收**：不用提示能有可破封印路徑；靠一般傷害不可跳階；有完整勝敗流程；同 seed 可重播戰鬥事件。

## P3：Roguelike 地圖、商店與局外成長

**工作**

- 10 層分岔地圖、節點、依 seed 可重現路線；普通怪與菁英資料化。
- 營火、商店、戰後獎勵、至少 5 種局內遺物（可先 2 種）。
- 局外商店四線三階、局內／局外貨幣與快照、存檔與復原。
- `RunResult` 完整結算、重複領獎防護、自動示範用於 QA（可選）。

**驗收**：每局有完整 10 層可通路線；存檔能還原；局外升級下局才生效；不同 seed 有合理變化；錯誤存檔不被靜默覆寫。

## P4：美術、音效、教學與品質

**工作**

- Pixel Art 主角與至少三種怪物（含 Boss）動作圖集；清晰破盾／治療特效。
- 由 Web Audio 合成原創地圖、普通戰、Boss BGM 與事件音效；支援靜音、音量、頁面暫停。
- 提示層級、練功房（教師可自訂弱點）、本機匿名行為記錄（可關閉）。
- 桌機／手機、鍵盤、色盲識別、reduced motion、離線、壓力與效能檢查。
- 固定種子平衡測試及調參，不據此直接宣稱教學成效。

**驗收**：`docs/11_QA_ACCEPTANCE.md` 的每項可驗證條件有證據；來源與素材授權確認，無個資外流。

## 開發分工（多 AI 可用）

- **Architect**：資料契約、設定、狀態與事件邊界。
- **Math/Board Engineer**：算術正確性、盤面 solver、掉落可解性。
- **Combat/Map Engineer**：敵人狀態、回合、Roguelike 地圖、經濟。
- **Frontend/UI Engineer**：Phaser、輸入、手機版、可及性。
- **Art/Audio Engineer**：Pixel asset pipeline、Web Audio 原創聲音。
- **QA/Education Critic**：數學例子、可重播測試、教育提示是否洩漏答案與數據限制。

多代理協作採唯一的 `docs/02_MATH_RULES.md` 與 TypeScript domain contracts 為準；各代理不能自行發明衝突的倍率或重新定義「消除」。
